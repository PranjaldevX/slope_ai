Binary Search: Implementation and Analysis

Binary search is a divide-and-conquer algorithm that finds a target value in a sorted array. It runs in O(log n) time by repeatedly halving the search space.

How It Works

The algorithm maintains two pointers: left at index 0 and right at the last index. Each iteration:

  1. Calculate mid = (left + right) // 2
  2. If arr[mid] == target, return mid
  3. If arr[mid] < target, search right half: left = mid + 1
  4. If arr[mid] > target, search left half: right = mid - 1

Python Implementation

def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1  # Not found

# Example usage
arr = [1, 3, 5, 7, 9, 11, 13, 15]
result = binary_search(arr, 7)
print(f"Found at index: {result}")  # Output: Found at index: 3

Time Complexity Analysis

Best case: O(1) - target is at the middle

Average case: O(log n) - target requires multiple comparisons

Worst case: O(log n) - target is at an end or not present

For an array of 1,000,000 elements, binary search requires at most 20 comparisons (log₂(1,000,000) ≈ 19.93). Linear search would require up to 1,000,000 comparisons.

Space Complexity

The iterative version uses O(1) space. A recursive version would use O(log n) space for the call stack.

Recursive Implementation

def binary_search_recursive(arr, target, left, right):
    if left > right:
        return -1
    
    mid = (left + right) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)

# Example usage
arr = [2, 4, 6, 8, 10, 12, 14]
result = binary_search_recursive(arr, 10, 0, len(arr) - 1)
print(f"Found at index: {result}")  # Output: Found at index: 4

Common Pitfalls

Integer overflow: In languages like C++ or Java, (left + right) / 2 can overflow. Use left + (right - left) / 2 instead.

Off-by-one errors: Ensure loop condition is left <= right (not left < right) and updates are mid + 1 and mid - 1 (not mid).

Unsorted arrays: Binary search only works on sorted arrays. Sort first with O(n log n) algorithm if needed.

Variations

Find first occurrence: When arr[mid] == target, continue searching left: right = mid - 1. Track the last found index.

Find insertion point: Return left when loop exits. This gives the index where target should be inserted to maintain sorted order.

def find_insertion_point(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return left  # Insertion point

When to Use

Binary search is optimal when:

  • Array is sorted (or can be sorted once and searched many times)
  • Random access is O(1) (arrays, not linked lists)
  • Dataset is large (n > 100)

For small datasets (n < 10), linear search may be faster due to lower constant factors.
