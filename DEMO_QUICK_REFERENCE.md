## 🚨 IF SOMETHING GOES WRONG

### Extension Not Working?
- Reload extension: `chrome://extensions/` → reload button
- Rebuild: `cd extension && npm run build`
- Reload page you're testing

### Forgot What to Say?
- Pause recording
- Check this card
- Continue (edit pause out later)

### Made a Mistake?
- Pause 2 seconds
- Say "Let me try that again"
- Continue from that point

### Nervous?
- Take deep breath
- Remember: You built something cool!
- Judges are developers, not critics
- Imperfect is fine!
